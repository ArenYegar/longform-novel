# 驿道三人

三个现代人，每天落进一个不同的朝代，落的点总在驿道附近。

他们决定不了落到哪，也拦不住下一次。

## 关于

历史穿越题材的长篇连载。写三个人被扔进不同的朝代，落在制度与人情最粗粝的地方：
驿道上、驿铺里、查验台前。他们靠一双手和一点现代常识，换一顿饭、一条活路。

每一章独立成事，前后又有伏笔相连。
